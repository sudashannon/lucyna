# 功能与当前边界

| 模块 | 已实现 | 依赖 / 边界 |
| --- | --- | --- |
| 原生会话 | 新建、流式响应、思考/工具过程、停止、原生消息队列、交互提问 | 由 OMP RPC 执行；具体模型能力由 provider 决定 |
| 并行工作 | 多 work / session 同时运行、切换不停止、独立草稿与状态 | 客户端需保持运行；不是无头任务调度服务 |
| 历史 | 按 work 列表、搜索、来源筛选、导入副本、续聊 | 同一 journal 只允许一个活跃写入者；不迁移所有第三方 session 格式 |
| 技能 | 读取原生命令目录、斜杠补全、技能调用 | 不内置或复制用户整套技能；需要原生 OMP 能发现技能 |
| 输入 | 大段文本、图片粘贴/附件、停止后还原排队草稿 | 图片支持与配额取决于模型；不自动扩展上下文上限 |
| 工作区 | 只读诊断、摘要、SESSION 阅读、分支偏差提示 | 不自动切分支或修改 Work 登记 |
| 终端 | 内嵌 xterm、WSL PTY、调整尺寸、按 session 保留 | Windows 桌面 + WSL；不是远端 SSH 管理器 |
| 阅读 | 文件列表、Markdown/GFM、语法高亮、公式、Mermaid、图片、网页 | 受工作根路径约束；网页能力受网站策略影响 |
| 知识 | 文档阅读/编辑/摘要、证据检索与版本定位、Cytoscape 社区图谱、会话记忆、时间线、资料导入、候选审核、知识复核、待办、报告、问答、备份恢复 | 需要已有 Stele 服务；知识库可见时每分钟读取更新；编辑与审核校验版本；恢复在 Stele 下次启动时应用 |
| 外观 | 深浅色、可调左右栏、窄窗布局、事件页、阅读位置保留 | 浏览器 `npm run dev` 仅 UI 预览，桌面能力需 Electron |
| 桌面伙伴 | 银发女孩与黑猫/黑猫两种外观，32 帧像素素材，状态动画、置顶、托盘、通知、静默与隐私设置 | 透明窗口、DPI、多显示器行为仍需持续实机验证 |
| 配置 | Windows / WSL OMP 切换、模型、环境检查、桌宠偏好 | 发行版、用户和 workRoot 当前在本地 JSON 配置 |

这是早期桌面客户端。当前重点是 Windows + WSL；没有声称支持 macOS/Linux 桌面发行版、多人协作服务、自动升级、无人值守任务恢复或所有 OMP 扩展 UI。演示截图使用合成数据，不代表已访问某个真实项目或调用了真实模型。

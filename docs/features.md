# 功能与当前边界

“设置 → 声音与动效”提供柔和合成器、像素电子两套原创音效，可试听完成、待回复和中断三种提示。默认专注模式只提示后台会话；陪伴模式也提示前台会话，静音模式保留文字状态。音量与各事件可以单独配置，保存立即生效，不需要重连 OMP。两秒内的会话提示合并发声，主动停止、单次工具失败和自动重试不发声；锁屏或静音期间的旧提示不补播。

声音独立于桌宠开关，桌宠勿扰会同时暂停自动声音。界面与桌宠共用减少动效开关，并遵循系统偏好。桌宠待回复只短暂招手后静止，中断、连接与停止使用独立动作节奏。新消息只在初次出现时淡入，不逐 token 动画；侧栏拖动保持直接跟手。本版自动声音消费普通 OMP 会话事件，尚未订阅独立 WSL Work Runner 服务的后台状态；客户端彻底退出后也不发声。

工作区列表支持最近使用、已打开会话、待处理或未读结果筛选。活跃会话分别解释连接状态与任务状态；历史条目突出原件/副本来源并可悬停查看路径与时间。三栏并排时优先保留约 640px 对话宽度，窗口变宽后恢复用户偏好的侧栏宽度。设置顶部可按类别跳转，并标明保存后的生效范围。

文档加载、读取失败和正文为空使用独立状态。文档列表的“搜索正文与证据”会携带关键词及来源进入检索：优先展示标题、标签或服务片段的关键词匹配，可展开仅语义相关结果；这是展示排序，不是可信度评分。选中结果后从当前原文快照提取正文片段，跳过 YAML 元数据，并附带可核对的行号与版本。后台任务与进化实验使用宽弹窗和固定操作区，提前显示普通连接及已有任务冲突；服务端仍在启动时再次检查。

| 模块 | 已实现 | 依赖 / 边界 |
| --- | --- | --- |
| 原生会话 | 新建、流式响应、思考/工具过程、停止、原生消息队列、交互提问 | 由 OMP RPC 执行；具体模型能力由 provider 决定 |
| 并行工作 | 多 work / session 同时运行、切换不停止、独立草稿与状态；重开时分批恢复上次连接及已完成未读；活跃会话页统一筛选、打开、停止、结束连接 | 普通任务执行期间客户端需保持运行；重开只恢复原会话连接，不重发任务。手动断开的会话保留在“全部打开”；打开前台会话才清除未读；停止后排队文本和图片回到所属草稿 |
| 历史 | 按 work 列表、搜索、来源筛选；WSL 原生历史原地续聊、显式创建副本、跨环境复制；会话、专属附件和对应 Work 备忘一起回收/恢复 | 删除前显示文件清单；连接中的会话禁止删除；不改共享摘要、笔记或 Stele；有歧义的备忘保留并说明；恢复不覆盖已有文件。旧版仅隐藏的记录仍可恢复 |
| 时间轴 | 宽窗口常驻旁侧目录，窄窗口显示细轨道；阅读位置高亮、搜索与分页；按提问、回答、工具失败与待回复跳转 | 不遮挡正文，无需打开或关闭；长历史仅渲染目标附近记录，不额外调用模型 |
| 技能 | 读取原生命令目录、斜杠补全、技能调用 | 不内置或复制用户整套技能；需要原生 OMP 能发现技能 |
| 输入 | 粘贴达到 100 行或超过 8,000 字符时转为文本附件；预览、移除、逐项选择全文发送；图片粘贴/附件、停止后还原排队草稿 | 默认只传原生 `local://` 引用，由 OMP 按需读取；正文和文本附件合计最多 4 MiB / 8 份。保存失败保留草稿；图片支持与配额取决于模型 |
| 工作区 | 进展/未决事项/最新记录；按仓库归组 Worktree，分支、基线、暂存/未暂存/未跟踪/冲突、diff、提交、同仓工作树、MR/流水线；实际笔记/日志/脚本/证据索引 | Git 只读、不 fetch 或改 Work 登记；远端引用为本机缓存，MR 按需通过 WSL glab 查询；勾选数不代表验收完成 |
| Work 后台任务 | 原生 OMP goal、界面退出后继续、暂停/恢复、持久答复；文件读写/搜索、skill 与 L3 读取、隔离命令、Git 只读查看；阶段与事件时间线 | WSL Python 3.10、systemd、bwrap；命令无网络与用户主目录，仅使用已挂载运行时；公共 L3/skill 不参与修改，Git 写入与设备操作仍走普通会话 |
| Work 进化实验 | 保存一次评测配置后，文件变化且空闲时自动调用 AntOmniEvo；有限恢复、分数曲线、候选 diff、人工采纳与校验回退 | 公共 L3/skill 只读；1–5 轮、最多 10 个现有文件；每 Work 滚动 24 小时最多自动 2 次；缺少训练/留出检查时等待配置，不自动构造任意任务训练集，不宣称长期泛化收益 |
| 终端 | 内嵌 xterm、WSL PTY、调整尺寸、按 session 保留 | Windows 桌面 + WSL；不是远端 SSH 管理器 |
| 阅读 | 文件列表、Markdown/GFM、语法高亮、公式、Mermaid、图片、网页 | 受工作根路径约束；网页能力受网站策略影响 |
| 知识 | 文档阅读/编辑/摘要、证据检索与版本定位、Cytoscape 社区图谱、会话记忆、时间线、资料导入、候选审核、知识复核、待办、报告、问答、备份恢复 | 需要已有 Stele 服务；知识库可见时每分钟读取更新；编辑与审核校验版本；恢复在 Stele 下次启动时应用 |
| 外观 | 合并菜单顶栏、原生窗口按钮；知识库使用独立导航与文档左栏，工作台和活跃会话共用工作区左栏；两套宽度、筛选和阅读位置分别保留；深浅色与窄窗布局 | 浏览器 `npm run dev` 仅 UI 预览，桌面能力需 Electron |
| 桌面伙伴 | 两种外观、32 帧像素动画、置顶、托盘；完成提醒包含最终回答摘录、耗时与工具统计；设置中可独立恢复桌宠，锁屏/休眠后自动重建可见桌宠 | 隐私模式隐藏结果摘录和完整路径；画布恢复会重绘，渲染进程崩溃最多自动重建两次/分钟；保留会话与待办，不自动打开被用户隐藏或关闭的桌宠；跨屏行为仍需持续实机验证 |
| 配置 | Windows / WSL OMP 切换、模型、环境检查、桌宠偏好 | 发行版、用户和 workRoot 当前在本地 JSON 配置 |

这是早期桌面客户端。当前重点是 Windows + WSL；没有声称支持 macOS/Linux 桌面发行版、多人协作服务、自动升级、普通任务故障后自动重放或所有 OMP 扩展 UI。普通交互会话仍由客户端持有；Work 后台任务和自动进化实验由独立服务持有。演示截图使用合成数据，不代表已访问某个真实项目或调用了真实模型。

# 功能与当前边界

OMP 会话已接入子代理与后台任务卡片：实时进度、命令与输出、独立停止、断线恢复、完成摘要和等待确认计时。后台命令／服务监控需要配套原生运行时；安装与兼容边界见 [OMP 任务监控](omp-task-monitoring.md)。

“设置 → 声音与动效”提供柔和合成器、像素电子两套原创音效，可试听完成、待回复和中断三种提示。默认专注模式只提示后台会话；陪伴模式也提示前台会话，静音模式保留文字状态。音量与各事件可以单独配置，保存立即生效，不需要重连 OMP。两秒内的会话提示合并发声，主动停止、单次工具失败和自动重试不发声；锁屏或静音期间的旧提示不补播。

声音独立于桌宠开关，桌宠勿扰会同时暂停自动声音。界面与桌宠共用减少动效开关，并遵循系统偏好。桌宠待回复只短暂招手后静止，中断、连接与停止使用独立动作节奏。新消息只在初次出现时淡入，不逐 token 动画；侧栏拖动保持直接跟手。本版自动声音消费普通 OMP 会话事件，尚未订阅独立 WSL Work Runner 服务的后台状态；客户端彻底退出后也不发声。

工作区列表支持最近使用、已打开会话、待处理或未读结果筛选。活跃会话分别解释连接状态与任务状态；历史条目突出原件/副本来源并可悬停查看路径与时间。三栏并排时优先保留约 640px 对话宽度，窗口变宽后恢复用户偏好的侧栏宽度。设置顶部可按类别跳转，并标明保存后的生效范围。

文档加载、读取失败和正文为空使用独立状态。文档列表的“搜索正文与证据”会携带关键词及来源进入检索：优先展示标题、标签或服务片段的关键词匹配，可展开仅语义相关结果；这是展示排序，不是可信度评分。选中结果后从当前原文快照提取正文片段，跳过 YAML 元数据，并附带可核对的行号与版本。后台任务与进化实验使用宽弹窗和固定操作区，提前显示普通连接及已有任务冲突；服务端仍在启动时再次检查。

工作台的 Stele 检索卡片在正文预览中复用共享 Markdown 渲染器，支持表格、代码、公式和任务列表；宽表格在卡片内横向滚动。缺表头的表格片段会注明数据不完整，原始摘录与版本信息仍可在详情中核对；预览补齐的空表头不会加入聊天引用。

聊天中的 Markdown 图片按所属会话的 Work 根和 SSH 主机读取，支持工作区相对路径、根内 Linux 绝对路径、点击或键盘放大、图片链接预览及失败重试。普通文件链接打开工作区阅读器，文档内图片继续按文档目录解析。切换会话会丢弃旧预览请求的显示结果。图片读取受工作区边界限制，本机上限 10 MiB、SSH 上限 1 MiB；网络图片暂不内嵌，HTTP(S) 链接仍在系统浏览器打开。

## 工作区文件与 Git 管理

当前 Work 的主内容区有「对话工作」和「工作区文件」两个标签。「工作区文件」把原有文件浏览和阅读放在主工作宽度内，并提供「浏览」「改动」「历史」「分支」「Worktree」五个视图。浏览继续使用现有 Markdown、文本、代码、配置和图片阅读器；改动按冲突、已暂存、未暂存和未跟踪分组，可分别查看未暂存、已暂存及登记基线到 `HEAD` 的差异，切换基线范围时会清除先前的单文件筛选；历史支持提交消息筛选、分页和提交差异，查询变化或刷新会重置旧游标；分支列表包含本地分支及本机缓存的远端引用，选择引用只比较它与 `HEAD`，不切换分支；Worktree 视图显示同仓工作树并提供受限管理操作。

改动视图可整文件暂存/取消暂存，也可选择由服务端生成并校验的 diff 块或行。提交只包含暂存区内容；提交检查已审阅的 tree 和父提交，保留正常 Git hooks/签名，并保留 hook/签名执行期间由其他工具独立暂存的内容。同步视图支持针对已配置远端 fetch 和 push；push 目标明确且会核对远端 ref，不提供 force push。分支管理支持从 `HEAD` 新建、切换并同步 Work 登记，以及 fast-forward-only 合并；不支持分叉冲突的图形化解决。Worktree 管理仅操作当前 Work 已登记的成员，可创建、改名/移动或移除成员；有改动、未跟踪文件、锁定或活动 Work 会话时拒绝生命周期操作。WSL 生命周期操作期间，socket 所有的租约会阻止 WorkRunner 普通任务和自动任务启动，并在 socket 关闭时释放。

本机 WSL 的 Worktree 面板可选择「审阅时仅检出指针」。审阅模式随成员登记，Lucyna 切分支或快进合并时继续保留 LFS 指针。构建前按仓库流程补齐资产。磁盘占用按需调用 WSL 上的 Work 技能，显示成员检出、展开的 LFS、忽略和未跟踪文件，并单独统计共享对象库。移除前若发现 Git 忽略的文件，会提示先走 Work 的归档流程。

操作 ID 和结果记录先持久化到执行主机；界面显示进度、近期历史与核对入口。断线或进程中断时不会自动重发，结果不确定会暂停该仓库的后续写操作，用户核对真实状态后才可解除限制。提交说明和待核对操作 ID 按 Work/host/成员保存在本机客户端；打开文件与阅读位置只在当前客户端运行期间保留。浏览文件不启动 OMP。

本机 Work 使用 WSL Git；SSH Work 需远端 host 公布工作区文件与 Git 能力，旧 host 可在「设置 → SSH 主机 → 更新主机组件」升级。远端文本/图片预览上限为 1 MiB；远端 Git 配置、凭据、hooks 和签名工具留在 host。需要交互认证或签名时，在 Git 所属执行主机的终端中完成。远端终端、附件落盘和 Work 后台任务仍未接入；SSH host 更新也要求没有活动会话或 Git 操作。

这是早期桌面客户端。当前重点是 Windows + WSL；没有声称支持 macOS/Linux 桌面发行版、多人协作服务、自动升级、普通任务故障后自动重放或所有 OMP 扩展 UI。本机普通交互会话由客户端持有，SSH 普通会话由远端 host 持有；Work 后台任务和自动进化实验由独立服务持有。演示截图使用合成数据，不代表已访问某个真实项目或调用了真实模型。

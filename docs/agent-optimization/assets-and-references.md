# Work 资料发现、引用与导入

状态为部分实现。本机 Work 资产页保留手动浏览、保存和引用入口；草稿提示现可按当前 Work 对话和资料元数据推荐本机 Work 文件或已保存资料。用户选中建议后，系统才读取所选资料快照。远端 Work 资产推荐、全局知识推荐和跨 Work 导入尚未接入。

## 已接入流程

1. 草稿输入提示服务从当前 Work 的会话上下文和本机资料目录中整理候选。模型只收到标题、路径、类型、版本和有限元数据，不会收到未选资料的正文。
2. 用户可打开资料建议查看关联原因，并显式选择“预览资料”。服务重新核对 Work、路径、资料版本和安全策略后，再通过既有 Work 资料服务读取正文快照。
3. 用户可选中已预览快照中的片段写入当前 OMP 草稿，也可只插入来源信息。正文引用带有资料名称、路径、Work 根目录，以及可用时的快照版本和 SHA-256 来源摘要。插入量和预览正文均有长度上限。
4. 草稿、光标、Work 或会话资料来源变化后，旧提示结果不能继续插入。读取前和读取过程中会核对资料版本；用户可以引用明确预览过的快照版本。引用只是草稿文本，最终由用户编辑和发送。

草稿提示的资料推荐只接本机 Work 文件和该 Work 已保存资料，远端资产推荐暂不可用。资料建议至多三项，受限目录中的笔记、日志、脚本、证据等通过现有 Work 资产策略筛选。读取疑似凭据内容会被拒绝。模型不具备文件工具，也不会写 Work 文件。

## 仍待实现

对话摘要当前引用会话中的用户和 OMP 原文，不会把 Work 资产或知识库正文自动塞入摘要上下文。助手也尚未依据其他 session 的工具产物进行自动推荐，不能跳回引用对应的原会话。

后续可以接入 Work 范围内的知识库检索、跨 Work 显式复制和结构化引用对象。跨 Work 导入应保留原来源并在目标 Work 建立独立副本。当前的草稿引用不会自动变成被发送消息上的结构化来源记录，也不代表模型已经阅读或验证该资料。

## 现有基础与边界

Work 资产页列出实际目录中的笔记、日志、脚本与证据路径，支持用户保存 Work 资料快照。用户也可从 Work 资产页直接选择获准的本机资料并加入当前草稿。知识阅读器可把已选知识内容引用到草稿；该入口不等于草稿提示中的全局知识推荐。

Work 资料属于其 Work 身份，与全局知识索引分开管理。来源版本变化时，旧的提示资料建议失效；捕获的不可变快照仍保留当时正文和来源摘要。敏感路径或正文按现有 Work 资料策略过滤，不因用户打开提示而自动加入辅助模型上下文。

# 提示词补全与继续工作

状态为首批功能已接入。Work 助手固定栏目摘要可生成“继续当前工作”草稿；输入中的提示词补全已接到本机与远端 Work 的 OMP 草稿。两者都只提供可编辑内容，不自动发送消息或启动会话。

## 当前行为

Work 助手将已载入的多 session 对话整理为工作概况、当前目标、决定与方向、进展记录、未决问题和建议下一步。摘要条目关联具体用户或 OMP 原文，可展开核对。该摘要是整个 Work 的固定栏目汇总，目前没有独立的工作主线识别、分组或逐主线 continuation。

“继续当前工作到草稿”将摘要、部分栏目和至多五条对话出处写入当前 OMP 输入框。较长内容会裁剪，并在草稿中说明未纳入的部分。摘要尚未与当前资料版本同步时，按钮不可用。用户可以继续编辑后自行发送。

输入补全在用户聚焦 OMP 草稿、输入暂停约 900 毫秒后请求。当前要求包括 Work 助手已启用、已有会话来源、草稿不超过 6,000 字符、光标位置稳定且没有选区、未处于中文输入法组合或命令补全状态。斜杠命令、疑似凭据内容和不符合条件的草稿不会请求提示。

辅助模型最多给出两条短补全，并为每条提供可核对的用户或 OMP 原文出处。系统会检查出处是否确实包含所引文字，并区分原文摘录与根据对话推导的建议。只有在草稿内容与光标仍匹配请求时，用户才能把候选插入原位置；接受和忽略均由用户显式操作。

本机与远端 Work 的已载入会话对话均可作为输入上下文。当前对话样本和会话描述有长度上限，界面提供来源和覆盖信息。提示请求由无工具的 AuxiliaryAgent 执行，不能发送 OMP 消息、建立会话或修改 Work 文件。

读取资料目录设有等待上限。若目录未能及时返回，界面说明资料暂不可用，仍可仅依据会话对话生成补全；目录请求可继续在后台完成并更新缓存。切换草稿或来源后，未完成的前置读取和模型请求会取消，避免过期结果回到当前草稿。

## 资料建议与边界

草稿补全服务同时可依据本机 Work 文件和已保存 Work 资料的标题、路径、类型与版本提出至多三条资料建议。模型收到的是筛选后的元数据，不会提前读取资料正文。远端 Work 的资产建议暂未接入；全局知识库推荐和跨 Work 资料推荐也仍待实现。详细资料范围见 [Work 资料发现、引用与导入](assets-and-references.md)。

接受资料建议后，用户可预览由既有 Work 资料服务读取的快照，选择正文片段加入当前草稿，或只加入路径、快照版本和摘要校验值。插入前会再次核对草稿、光标、Work 身份与来源版本。反馈计数仅在当前进程内按 Work 暂存，不构成持久化偏好或学习模型。

## 数据归属与下一步

补全结果绑定 Work 身份、当前 OMP session 草稿、草稿修订、光标位置和会话资料版本。切换 Work、session、资料版本或编辑草稿后，旧候选失效。来源身份使用原生 session/message 标识，不从标题推断。

后续可以加入用户可选择的结构化任务整理、当前工作范围选择和跳回原始 session 的入口。主线归组和逐主线摘要须在基础多 session 汇总稳定后再做；跨 Work 偏好不从单次接受或忽略行为推断。

## 现有基础

会话草稿已有按 session 身份持久保存、OMP 原生消息队列、停止后恢复和斜杠命令补全。摘要与输入提示使用各自受限的 AuxiliaryAgent 请求，OMP 原生会话仍负责主会话及其工具调用。

# SSH 会话与远程 Work

状态为部分接入。本机与远端 Work 页面都已显示 Work 助手。已打开且能读取 journal 的 SSH 会话事件可以进入摘要，并按 hostId 与远端 Work 根隔离；远端历史批量补齐和 Work 文件资产读取尚未接入。

## 当前基础

远端服务持有 OMP 进程及 journal，通过 SSH 传递状态、消息和交互请求。断线重连校验 host 安装身份和 session 代次。存在确认不明时，以持久 operationId 查询结果。renderer 用 hostId 和原始 Linux Work 根区分远程 Work。

## 改进方案

1. 汇总经 SSH 适配器确认已载入的会话和历史，显式标出尚未同步的资料。
2. 增加远端可用能力声明，使 Work 助手能区分 session 历史、Work 文件、知识和 Runner 能力。
3. 将远端摘要、草稿建议和资料引用都绑定 hostId、root、session 和来源版本。
4. 断线后先恢复会话身份和数据状态，再恢复建议；不把尚未确认的操作写成已完成。
5. 远端 Runner 和资料导入在各自的 Work / 主机适配层实现。

## 数据和模型边界

主机凭据、SSH 登录环境及远端 provider 凭据由现有宿主处理。Work 助手只经受信 host 接口读取声明过的能力。不将本机缓存的远端资料描述为当前远端状态。

远端 session 摘要仍然是该 Work 的 session 摘要，但保留其 host 来源。服务已把 hostId 和原始 Linux Work 根纳入摘要身份；当前远端批量历史入口明确返回不支持。不能与相同路径的本机 WSL Work 自动混并。

## 未完成范围

远端批量历史补齐、资产与知识引用、终端、附件落盘和 Work 后台任务仍未接入。多实体主机、跨架构和冷启动行为尚未完整验证。已打开会话的对话摘要能显示在远端 Work 页面；摘要来源之外的远端材料仍需逐步接入。

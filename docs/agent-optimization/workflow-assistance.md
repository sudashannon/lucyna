# Work 流程提醒与偏好

状态为部分实现。Work 助手现提供会话交接、维护 `SESSION.md`、重复阻塞和复用已有成果四类流程提醒。提醒由 Work 对话和可读取的当前 Work 记录生成，显示在本机与远端 Work 助手面板。独立的用户偏好引擎、资料自动登记、文件改写和后台任务动作仍未实现。

## 提醒来源与触发

流程提醒独立于 Work 摘要运行。只要 Work 助手已启用并且存在可分析的跨会话对话来源，来源修订变化会安排分析；打开 Work 助手读取状态时，如果当前 Work 资料和辅助模型配置尚无成功分析结果，也会安排首次或补充分析。摘要生成失败或摘要版本落后不会阻止流程提醒。用户可在面板手动重新分析；相同 Work 资料和模型配置不会被自动重复请求。

发送给模型的对话和 `SESSION.md` 内容会切成不超过 800 字符的精确摘录，每段带本次请求专用的 `evidenceId`（如 `c1.1`、`r1.1`）。模型只需返回摘录 ID；服务端会从仅在本次请求内有效的映射还原原生来源和摘录，再按原始对话或文档重新核对。额外传递 `sessionLabel`，帮助模型判断两个摘录是否来自不同会话，但不会发送原生 session/message 标识。这样引用不依赖模型逐字复写长文本，也不能伪造来源或引用未发送的内容。

跨会话分析使用后台长任务调用，单步骤和总时限均为 600 秒，不设置固定的输出 Token 上限，以给较慢的推理模型留下完成结构化结果的时间。超时、配置或模型错误不会产生成功分析记录；未完成的模型输出也不会保存。

每次分析最多保存五条提醒，候选严格限定为以下类型：

- **会话交接**。会话明确表达了需要携带当前上下文、未完成工作或决定继续推进。
- **维护 `SESSION.md`**。用户明确改变决定或计划，并且当前 `SESSION.md` 中有实际记录可供核对。仅有文字差异或缺少记录不构成冲突证据。
- **重复阻塞**。至少两条不同对话消息明确显示同一问题仍未解决；已出现解决证据时不提示。
- **复用工作成果**。较早对话记录了具体结果，后续会话再次调查或询问同一事项。除非来源明确说已验证，不把建议或计划描述为已完成。

每条提醒都须引用确切的用户、OMP 或 `SESSION.md` 原文。不能提供匹配来源的候选会被拒绝。辅助模型没有工具，不访问文件、不启动任务，也不能声称已维护记录。来源变化或服务配置变化会取消正在运行的旧请求，并阻止过期结果提交。

## 文档读取范围

本机 Work 从当前登记 Work 根目录受限读取 `SESSION.md`，最多提供 48,000 字符并标记截断。远端 Work 只在对应 SSH 连接已存在且可用时读取；系统不会为提醒自动建立或恢复远端连接。远端文档不可用时，仍可根据会话出处形成交接提醒，但没有真实文档摘录时不能产生 `record_update`。

每个 Work 的提醒和状态单独持久化。提醒使用 Work 身份、稳定语义 key 和支持来源指纹维持身份。模型会看到有界的历史提醒标识作为去重线索，但这些标识不是当前事实或可引用证据。原生消息身份与消息文本参与证据指纹，因此只改变摘录窗口或出现无关新消息，不会让同一已忽略事项重新出现；支持证据本身改变后会重新判断。

流程状态保留 `lastAttemptAt` 与 `lastSuccessAt` 两个毫秒时间戳：前者记录最近一次实际开始分析的时间，即使分析失败也保留；后者只在结果通过引用校验并成功持久化后更新。有效的空提醒列表也是成功结果。`currentAnalysis` 仅在最近一次成功结果仍匹配当前对话、`SESSION.md` 内容和辅助模型配置时为真。界面不得用状态更新时间 `updatedAt` 代替检查时间，也不得把零时间戳显示成已检查。

删除某个会话时，Work 助手的会话来源与由其衍生的流程提醒一并清理，避免摘要或提醒保留被删会话的派生文字。

## 生命周期和用户操作

提醒支持新建、已查看、已完成、稍后处理和忽略状态。稍后处理在 24 小时后重新显示已有提醒，不会单独触发新的模型分析。来源或 `SESSION.md` 发生变化时，旧提醒标为过期并暂不可操作，用户可以重新分析。

用户可以展开查看每条提醒引用的对话摘录或文档摘录，也可以标记已查看、完成、稍后、忽略，或将提醒草稿加入当前 OMP 输入框。写入草稿时会附上 Work 身份、对话 session/message 标识和文档哈希，供用户复核。写入仅改变当前草稿，不会自动发送消息、改写 `SESSION.md` 或启动任务。

## 偏好和后续工作

当前持久化的是提醒生命周期和去重状态，不是用户偏好模型。接受、忽略和资料使用行为不会形成可跨会话复用的个性化规则。未来可以让用户查看、编辑或清除 Work 范围内的偏好，再考虑主线特定的触发频率与资料登记建议。

# 知识沉淀与维护

状态为已有 Work 经验沉淀与知识库自动维护功能的协作增强。Work 助手集中当前工作的资料状态，知识库承载适合长期复用的经验和规范。

## 已有能力

Work 空闲时，AuxiliaryAgent 可从指定 L1 笔记和 L2 日志提炼带来源引用的结论，写入内部知识库。来源发生变化后，知识维护可追踪受影响文档、生成局部修订并由宿主和模型复核，然后重新索引和核对检索版本。维护记录保留历史和人工冲突。

## 与 Work 助手的协作

- 在 Work 资料推荐中标明知识文档及其适用范围、维护状态和来源版本。
- 提示词补全引用知识库内容时，提供精确摘录和文档来源。
- 知识维护发现文档待核实时，在相关 Work 提醒用户检查受影响结论。
- 用户从一项工作中保存长期经验时，明确说明来源从 Work 资料进入公共或项目知识范围。
- Work 汇总记录当前进度，知识库保留经过整理的长期经验，两者通过出处链接关联。

## 处理与权限

工作流 Agent 无直接写知识库权限。模型生成结论和修改建议，知识宿主负责检查引用、版本和提交范围。维护结果标记为“原文仍适用”“局部修订”或“待核实”，语言模型复核不表示真实世界结论已被独立证明。

来源改变或冲突时保留原文和旧结论，并显示“待核实”。只有用户在明确操作中选择后，Work 资料才成为其他 Work 可引用资料。

## 继续改进

先让 Work 助手消费现有来源状态与已保存的 Work 资料，再实现跨 Work 的资料建议和知识转入流程。知识维护已经在进行的范围以 [维护说明](../knowledge-maintenance.md) 为准。

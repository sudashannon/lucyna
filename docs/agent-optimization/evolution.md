# 自动进化的产品定位

当前 AntOmniEvo 接口能以隔离副本和冻结评测围绕选定文件生成候选，并由用户采纳。后续产品入口调整为高级实验能力。

Work 的“自动进化”重心迁到 Work 级协作辅助。主要能力包括多 session 状态汇总、基于对话的提示词补全、已有资料推荐、任务交接和流程维护提醒。它们帮助用户推进整个 Work 的多条工作主线，不依赖生成代码候选。

## 当前实验的保留方式

已有 AntOmniEvo、自动评测准备、正反对照、独立副本、候选比较、人工采纳与回退继续归到高级实验。新建 Work 的局部文件自动实验策略默认关闭。可兼容地从历史 evolution Run 恢复实验配置，但不据此推断用户同意自动运行。已保存的自动策略继续按持久化的 `enabled` 值读取，已有 Run、实验配置和结果仍由当前 Work Runner 机制读取。

用户可以在 Work Runner 中手动配置实验并显式开启自动运行，也可以从 Work 文档手动发起评测准备。自动实验关闭时，日常进展入口指向 Work 助手，由它汇总多 session 状态并提供对话辅助。这样保留成熟的局部实验能力，同时不把它设为普通 Work 的默认行为。

## 与 Work 助手的关系

Work 助手可以把实验 Run 当作一类来源，显示目标、被评估的工作范围、结果、候选和人工状态。实验结果关联到相应主线供用户参考。它本身不替代真实项目依赖、设备、线上环境或工程回归的独立判断。

## 入口与数据迁移方向

在用户界面和帮助文档中将 Work 助手定位为持续协作功能，将 AntOmniEvo 标记为高级实验。更改入口和默认行为时，应按运行能力、手动配置、自动配置分别处理，保留既有 Run、评测和候选的可读性，并尊重已有策略中用户明确保存的启用状态。
